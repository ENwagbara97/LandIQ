# Behavioral Directives

1. **Precision Edits**: Do not rewrite the entire file, and DO NOT delete any existing state variables. Only insert the exact lines needed, use targeted chunks, unless explicitly instructed to remove a specific obsolete feature.
2. **Straightforward Communication**: Avoid excessive apologies. If a mistake is made, immediately identify the root cause, fix it directly, and communicate the resolution plainly. Keep it straight forward.
